# Hi, I'm Jacob

Founder and solo developer of [TraxIt](https://www.traxitapp.com/), a field-service app for fire protection contractors. It's on the Apple App Store and in production use.

## TraxIt

- Next.js web app and server API, plus an Expo (React Native) mobile app
- PostgreSQL with Drizzle ORM
- Offline-first mobile sync with PowerSync
- Clerk auth, Vercel hosting, GitHub Actions CI
- QuickBooks Online integration

## Skills

- **Languages:** TypeScript, JavaScript, SQL, Rust, Java, C#, C++
- **Web / Mobile:** Next.js, React, Expo (React Native), Node.js
- **Data / Sync:** PostgreSQL, Drizzle ORM, SQLite, PowerSync
- **Cloud / DevOps:** Linux, Vercel, GitHub Actions, Docker Compose, Cloudflare R2, Clerk
